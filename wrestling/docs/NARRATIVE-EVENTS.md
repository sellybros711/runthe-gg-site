# Run The Ropes: the event catalog

Every event, arc step, legend beat, epilogue and secret ending, as data. NARRATIVE.md is the
design; this is the content it calls for. 489 rows: 57 arcs (a01 to a57), 36 origin beats
(org_), 40 weekly singles (day_), 12 legend arcs plus the legend gate (L00 to L12), 36
epilogue beats (epi_) and 8 secret endings (sec_). Rarity: 136 common, 210 uncommon, 77 rare,
66 legend.

Columns: **needs** is the prerequisite, **choices** are separated by ` / ` and each carries
its layer tag ([R] real, [K] kayfabe), **consequences** and **flags** line up with the
choices in order. **follows** names the rows a choice can lead to; every id there is a row
in this file, a secret ending (sec_) or an ending flag (e_ legacy outcome, h_ Hall tier) from
NARRATIVE.md section 10. Real people never appear here: every name is invented.
