About Segue

Segue is a free setlist-builder game about jam bands, played in the browser with nothing to download and no account required. You are handed real concerts and asked to build a better night out of them.

How a round works

Pick a band. Each round spins up one real concert from that band's history, and you pull a single song off it. The song's actual running time comes off your set clock, so a twenty-minute jam costs what a twenty-minute jam costs, and the choice is always the same one: take the song you want, or take the song that fits.

You build two sets and an encore. Each has its own curfew, and every pick is final: there is no undo, so a set that runs long is a set you have to finish long. When the encore closes, the night plays back song by song to a crowd that reacts to what you actually booked.

Segues

Songs that ran into each other on the night can run into each other in your set too. Chaining them is worth more than playing the same songs apart, which is the whole argument the game is making: a setlist is not a list of good songs, it is an order.

Where the shows come from

Every concert, song and running time is real. The current band is goosetheband, with 7,504 recorded performances across 655 shows between 2014 and 2026, taken from the community archive at elgoose.net. Nothing is generated: if a show is in the game, it happened, in that order, at that length.

Segue is an unofficial fan project. It is not affiliated with, endorsed by, or connected to any band, venue or promoter, and all song and band names belong to their respective owners.
