## What counts as done

Each strip is one PNG, frames laid out left to right, 64x64 each, the
character facing RIGHT. Left facing is produced by flipping at draw time,
so it must never be drawn or shipped.

| animation | frames |
|---|---|
| idle | 2 |
| batting_stance | 1 |
| swing | 4 |
| pitch | 4 |
| run | 4 |
| celebrate | 2 |

Three things the audit will reject, so they are worth knowing before
drawing rather than after:

- **Nothing may touch x=0 or x=63.** Leave a column of transparent pixels
  down both sides. A bat or a staff that reaches the edge has been cut off,
  and the missing part cannot be recovered from the file.
- **No background.** Transparent means transparent. A filled rectangle
  behind the character is removable but it hides the silhouette, and on a
  dark page nobody can see that it is there.
- **The feet land on y=62**, not y=63, so the character has a pixel of room
  under it. The repair pass shifts this, but only if there is art to shift.
