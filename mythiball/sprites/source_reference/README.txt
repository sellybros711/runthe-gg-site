RunTheAllStars - Public Domain Character Sprite Pack (v2)
=========================================================
68 characters, hand-authored 64x64 pixel art with a shared
lighting model and colour-tinted outlines.

FOLDERS
- sprites_64/front/   64x64 front-facing  (humanoid characters)
- sprites_64/right/   64x64 right-facing  (all characters)
- sprites_64/left/    64x64 left-facing   (all characters)
- sprites_x4/...      the same art pre-scaled 4x (256px) for menus,
                      character-select cards and roster screens
- contact_sheet.png   the whole roster at a glance

TECHNICAL
- Transparent background, no anti-aliasing. Scale with
  NEAREST-NEIGHBOUR only, or the pixels will blur.
- Every sprite sits on the same 64x64 grid with feet near the
  bottom edge, so they line up without per-character offsets.
- Light source is consistent (upper-left) across the whole set.
- Outlines are tinted from the adjacent fill colour rather than
  flat black, which keeps light characters from looking sooty.

ROSTER NOTES
- Creatures that only read in profile (Great Ape, Nessie, Dragon,
  Phoenix, Black Cat, Rabid Dog, Chupacabra, Centaur) ship as
  right/left only. Everyone else has all three views.
- Designs reference public domain and folklore sources only.
  Filenames use the safe names: great_ape, lady_liberty, nessie.
