Country flag SVGs (4x3) bundled from the flag-icons project.

Source:  https://github.com/lipis/flag-icons
License: MIT (see the flag-icons repository for the full text)

Files are named by ISO 3166-1 alpha-2 code (lowercase), e.g. fr.svg, jp.svg.
The game (globe/index.html) derives the ISO code from each country's emoji flag
and loads the matching SVG here; if a file is missing it falls back to the emoji.
