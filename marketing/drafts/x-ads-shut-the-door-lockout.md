# X Ads: Shut The Door lockout trailer (DRAFT, for the owner)

Drafts only. The owner sets up and pays for the campaign in ads.x.com. Each list below is one paste:
X Ads Manager takes keywords and handles one per line (or comma separated) in its bulk box.

**Copy rule for this ad:** the lockout is the owners' move. Nothing here blames the players.
**Date rule:** from 2026-11-16 each day's spot is picked by the vote, so no ad says which closer is
today's. The trailer shows one real spot; the copy says "a new real save situation every day".
