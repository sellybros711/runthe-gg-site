About Run The Arcade

What is Run The Arcade?

Run The Arcade is a set of ten quick daily sports games in one place, sharing one streak ticket, one leaderboard family and one account. Every puzzle refreshes at midnight local time and everyone plays the same board, so the results are comparable and the group chat arguments are fair. Nothing installs: every game runs right in the browser.

  • Common Ground: sixteen names, four hidden groups of four.
  • Sportegories: one letter, eight categories, two minutes.
  • Alma Mater: name every player's college.
  • Career Path: identify the athlete from their club-by-club journey.
  • Daily Crossword: a sports mini against the clock.
  • Odd One Out: four share a link, one does not.
  • Guess the Player: crack the mystery athlete in eight guesses.
  • Rank It: order five careers by one stat.
  • Number Game: type the jersey number they wore.
  • High Low: an endless higher-or-lower streak.

A free RunThe.GG account plays Common Ground, Sportegories, Alma Mater and Career Path every day, and the Arcade Card opens all ten without limits, plus the Archive of past days. The same account carries your trophies and streaks across every game on RunThe.GG.
